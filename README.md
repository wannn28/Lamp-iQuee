# Fold Lamp

A local demonstration page for a fictional desk lamp. It is not a store: there is no cart, no checkout, and the contact form does not send anything.

```bash
npm install
npm run model   # rewrites public/fold-lamp.glb
npm run dev
npm run build
```

The model is generated by `scripts/make-lamp.mjs` and has three meshes: `shade`, `bulb`, and `base`.

## Tech stack

- Vite and React for one product page.
- Three.js, rendered with React Three Fiber. The lamp is a GLB with meshes named `shade`, `bulb`, and `base`. The cord, socket, and bead are extra meshes in the page, not extra files.
- No database. Finishes and the written specifications are in the page itself.
- The contact form only keeps the name on the page. It does not send mail or store a message.
- The built site is static files. There is no cart and no checkout.
